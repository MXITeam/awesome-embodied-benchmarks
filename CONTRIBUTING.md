# Contributing

Thanks for helping keep this list comprehensive and accurate!

1. Put the benchmark in the **most specific** category (a benchmark may appear in at most two sections).
2. Use the table format: `Name | Year / Venue | Type | Highlights | Link`.
   - **Type**: `Sim`, `Real`, `Real2Sim`, `World model`, `QA`, or combinations.
   - **Highlights**: one line — scale (tasks / scenes / episodes) and what makes it distinct.
   - **Link**: prefer `https://arxiv.org/abs/XXXX.XXXXX`; otherwise the project page or venue page.
3. Mark benchmarks first released in the current year with 🆕; 🔥 is reserved for de-facto standards.
4. Keep rows sorted by year within each table.
5. Replacing an `arXiv search` link with the verified abstract link is a very welcome PR.
